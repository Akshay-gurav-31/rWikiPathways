About rWikiPathways

rWikiPathways is an R Client library for the WikiPathways API (license: MIT). This package allows you to access and analyze biological pathway data directly from R.

WikiPathways is described in the following papers:

  • 2016 NAR paper by Kutmon et al.
  • 2018 NAR paper by Slenter et al.

Key Features

Search & Retrieve

Easily search, browse and download pathways based on identifiers, names, or organisms.

Pathway Analysis

Perform pathway analysis with your omics data to uncover biological insights.

Identifier Mapping

Integrate with BridgeDbR for cross-platform identifier mapping capabilities.

Network Visualization

Visualize pathways using RCy3 and Cytoscape for interactive exploration.

How to Install

Official Bioconductor Release (Recommended) 
if (!requireNamespace("BiocManager", quietly=TRUE))
    install.packages("BiocManager")
BiocManager::install("rWikiPathways")

Note: Be sure to use the latest Bioconductor and recommended R version

Development Version (Latest Features) 
install.packages("devtools")
library(devtools)
install_github('wikipathways/rWikiPathways', build_vignettes=TRUE)
library(rWikiPathways)

Warning: Development code may contain experimental features

Troubleshooting

If you see this error on a Mac: make: gfortran-4.8: No such file or directory, try reinstalling R via homebrew: brew update && brew reinstall r
Warning: this may take ~30 minutes
